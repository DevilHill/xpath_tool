XPath Studio 浏览器元素定位工作台

XPath 工作台

先抓取浏览器中的元素，再校验 XPath

抓取元素

在网页中悬停，↑ / ↓ 切换层级，Ctrl＋左键锁定，Enter 确认。

连接浏览器扩展安装扩展后即可抓取与同步高亮。

等待抓取元素

确认后，这里显示候选定位器。

匹配结果 —

校验后，浏览器匹配元素会同步高亮。

AI 接口设置

兼容 OpenAI 协议的任意服务（OpenAI / DeepSeek / 通义千问 / Moonshot / 本地 Ollama 等）。配置保存在本机；调用 AI 时将提交的网页内容发送至配置的模型接口。

浏览器扩展联动：保存后会同时写入本地配置文件，浏览器扩展的「AI」标签页会通过 http://127.0.0.1:8790 复用这里的设置。请保持桌面版处于运行状态。

安装到正在使用的浏览器

扩展负责在浏览器里悬停高亮并把选中的元素回传到桌面版。安装后扩展会通过 WebSocket 自动连回本机服务，连接成功这里会显示绿点。

默认在现有浏览器中安装：点击下方按钮打开扩展页，开启「开发者模式」，再点「加载已解压的扩展程序」。扩展目录会自动复制，请在目录选择框中粘贴。Chrome 需要你手动完成加载。
