Playwright 定位器

执行校验后显示匹配到的节点。

用一句话描述目标元素，由大模型分析页面结构后给出稳健 XPath，并自动用本地引擎校验。

每行一个定位器，一次性校验是否有效、匹配多少个节点，快速发现失效的旧选择器。

自动找出页面中所有可交互元素（按钮 / 链接 / 输入框 / 表单控件等），为每个元素给出最稳健的定位器，适合快速搭建页面对象。

AI 接口设置

兼容 OpenAI 协议的任意服务（OpenAI / DeepSeek / 通义千问 / Moonshot / 本地 Ollama 等）。配置仅保存在本机浏览器，不会上传。

浏览器扩展联动：保存后会同时写入本地配置文件，浏览器扩展的「AI」标签页会通过 http://127.0.0.1:8790 复用这里的设置。请保持桌面版处于运行状态。

安装到正在使用的浏览器

扩展负责在浏览器里悬停高亮并把选中的元素回传到桌面版。安装后扩展会通过 WebSocket 自动连回本机服务，连接成功这里会显示绿点。

默认在现有浏览器中安装：点击下方按钮打开扩展页，开启「开发者模式」，再点「加载已解压的扩展程序」。扩展目录会自动复制，请在目录选择框中粘贴。Chrome 需要你手动完成加载。
